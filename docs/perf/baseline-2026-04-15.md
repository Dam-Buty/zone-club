## Conditions hors mesure
- Batterie Pixel 9 > 50% (éviter thermal throttling).
- Pas de background apps lourdes.
- Scène chargée, attendre 10s idle avant chaque run.
- Overlay perf actif (`?perf=1`), reset janks entre runs en rechargeant la page si nécessaire.

## Méthode de lecture de l'overlay
Pendant la rotation / le tutorial / le 1er passage, regarder l'overlay et :
- Noter la valeur **fpsMin** la plus basse observée pendant la fenêtre de 60 samples.
- Noter la valeur **fpsP5** la plus basse observée.
- Le compteur **Janks >33ms** est cumulatif depuis le chargement — noter la valeur finale et soustraire la valeur initiale avant le test si besoin.

## Validation
3 runs par scénario avec écart < 10% ⇒ chiffres fiables.
Si l'écart > 10%, refaire le run (thermal throttling ou interférence Wi-Fi probable).
